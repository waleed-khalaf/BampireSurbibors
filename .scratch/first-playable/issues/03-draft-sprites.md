# Draft sprites and palette

Status: ready-for-agent
Blocked by: 01

A script in `tools/` that generates PNGs into `assets/sprites/` from code-defined pixel grids (ported from the style-comparison prototype).
- `palette.png`: the shared palette.
- `shireen.png`: a 32×32 sheet with 2-frame idle-shimmy and 4-frame walk.
- `dowry_uncle.png`: a 32×32 sheet with 2-frame walk/bob and a swoon frame.
- `cash.png` (small bill, 3 sizes), `zill.png`, `sand_tile.png` (a seamless 64×64), `heart_pop.png`.
- All of these are drafts the user will refine in LibreSprite, so keep the sheets simple and documented (frame order in a header comment).
