# AGENTS.md

## Agent skills

### Issue tracker

Issues and tickets live in GitHub Issues (`waleed-khalaf/BampireSurbibors`), managed with the `gh` CLI. Specs live in `docs/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, each label equal to its name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
